## Установка

```bash
git clone https://github.com/JemmaperXD/SDDMTheme-GruvboxLight
cd SDDMTheme-GruvboxLight
./install.sh
```

Проверить без перезагрузки:

```bash
sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/gruvbox-ink
```
